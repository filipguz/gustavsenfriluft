# 🌊 Gustavsen Friluft — Nettside

Dette er den offisielle nettsiden for **Gustavsen Friluft**, et lite foretak på Sørlandet 
Siden fungerer både som en landingsside og en digital CV/portfolio for Filip Gustavsen.

Nettsiden er laget i **ren HTML/CSS/JS**, uten rammeverk, for å være rask, lett og enkel å vedlikeholde.

---

## 🚀 Funksjoner

- Presentasjon av foretaket *Gustavsen Friluft*
- Digital CV for Filip Gustavsen  
- Kontaktinformasjon med `mailto:` og `tel:`  
- Presentasjon av tjenester (surf, windsurf, livredning, bedriftskurs)
- Responsive layout  
- Minimal avhengigheter  
- Lett å hoste på GitHub Pages eller Netlify

---

## 🧱 Teknologi brukt

- **HTML5**
- **CSS3 (custom, no frameworks)**
